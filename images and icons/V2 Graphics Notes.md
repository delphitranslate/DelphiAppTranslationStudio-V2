# Version 2 graphics

The established `DelphiAppTranslationStudio-Icon-Master-v2` files are the
product's App Translate brand. The `v2` in those filenames names an artwork
revision; it is not a Version 2 software claim. Do not replace or redraw the
master icon merely to change the application version.

`V2-Badge.svg` and its PNG rendering are Version 2 labels.
They use the established blue and orange colors but are not the application's
taskbar icon. `Delphi-App-Translation-Studio-V2-Graphic.png` is a
concept graphic for internal guide/review use. It illustrates French UI text
becoming German UI text and intentionally shows no Pascal source rewrite.
The graphic was made with the built-in image-generation tool using the
existing App Translate master icon as a visual reference; its drawn logo is
an illustration, not an exact substitute for the master icon. Use the real
master icon for application branding.

The `1.0.0-Release-Announcement` and `Beta-Testing-New-Website` images are
historical publication assets. They are not V2 artwork and must not be
relabeled or republished as a V2 release. The repository-root `Images` folder
and website `assets/app-translation-icon.png` continue to carry the approved
product mark for the current public site.
