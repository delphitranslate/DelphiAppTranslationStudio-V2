# Delphi App Translation Studio 2.0 Is Now Released

Start with any supported source language, not just English. Delphi App Translation Studio 2.0 helps you translate a VCL or FireMonkey application into the supported target languages you choose. Add one language for a quick test or prepare several for release.

The Setup Wizard guides a new project through scanning, translation, review, and deployment. Come back to the Maintenance Studio whenever you need to add languages or refine existing translations. Your finished application loads its language packs locally, with no translation-service connection required at runtime.

Version 2.0 includes Win32 and Win64 Studio applications, RAD Studio 13 Florence integration packages, VCL and FireMonkey samples, and guides. DeepL and Google Cloud Translation Basic v2 can provide translation drafts through your own account and key; provider charges may apply.
